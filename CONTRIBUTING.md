# Contributing

Contributions must follow the Moodle coding style and preserve the shared
InteractEmbed contract with `block_interactembed`. Changes to shared source,
package, presentation, security or administration behaviour must be reflected
in both plugins or documented as a context-specific difference.

Run Moodle Plugin CI, PHPUnit, Behat, JavaScript, CSS, Mustache, PHPDoc and Code
Checker validation before proposing a release. Never commit credentials,
learner data or private packages.
